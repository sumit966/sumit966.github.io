## 🎯 About This Repository

This is the **source code for my personal portfolio website** — a modern, fully responsive, and animation-rich site built to showcase my work as an **AI/ML Engineer**.

> **🌐 Live URL:** [sumit966.github.io](https://sumit966.github.io)

The site includes:
- An **animated intro** with 10 scenes and holographic grid
- **AI chat interface** demo
- **Orbital icon** visualizations
- **Role-based** project showcases
- **Downloadable resumes** (force-download enabled)
- **WhatsApp** floating button for direct contact

## 🚀 Run Locally

```bash
# Clone the repo
git clone https://github.com/sumit966/sumit966.github.io.git
cd sumit966.github.io

# Open directly in browser
# Option 1: Double-click index.html
# Option 2: Serve locally (recommended)
python -m http.server 8000
```

Then visit `http://localhost:8000`.
